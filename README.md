# VacantSpot

VacantSpot is a modern platform for finding verified vacant houses in Abuja, Nigeria.

## 🚀 Quick Start

1. **Clone and Install**:
   ```bash
   git clone <repo-url>
   cd vacantspot
   npm install
   ```

2. **Configure Environment**:
   Copy `.env.example` (if available) or create `.env.local` with your Supabase and Paystack credentials.

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

## 🛠 Tech Stack

- **Framework**: Next.js 16.2 (App Router)
- **Styling**: Tailwind CSS 4
- **Backend**: Supabase (Auth, DB, Storage)
- **Payments**: Paystack

## 🔒 Verification

Every property on VacantSpot is physically verified to eliminate fraud and fake listings.
